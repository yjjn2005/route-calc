# 가는길 계산
대중교통·택시·자가용 시간과 비용 비교. GitHub Pages에서 index.html을 제공합니다.

## 검증 수정 (2026-09-30)
- 택시 총액과 요금 범위에 통행료를 정확히 합산합니다. 심야할증은 미터요금에 적용합니다.
- 연비·기본거리·요금 단위의 0, 음수, 잘못된 숫자를 검증합니다.
- 정수·소수 좌표를 지원하고 위도·경도 범위를 확인합니다.
- 입력 변경·장소 선택·출발지 교환 시 이전 자동완성 요청과 예약 작업을 무효화합니다.
- 중복 계산을 막고, 도로 조회 실패 시 경고와 점선으로 구분한 추정값을 제공합니다.
- 동일 ODsay 경로는 3분간 캐시하며 호출 한도 오류 후 5분간 재호출을 중단합니다.
- 이동 방향을 확인한 열차만 도착정보로 안내합니다.
- 손상된 검색 기록, 네트워크 실패, 오래된 역 도착 응답을 방어합니다.
- 설정 저장 시 경로를 다시 계산해 도보 속도와 주변 역 설정도 반영합니다.

## 검증
Node.js 18 이상에서 `node tests/regression.cjs` 실행. 계산·입력·캐시·장애 복구 23개 검증 그룹.

## 정확도와 운영 한계
공개 HTML에 포함돼 있던 기본 API 키를 제거했습니다. ODsay 실경로 조회는 사용자가 발급한 키를 설정에 입력해야 합니다. 키가 없거나 ODsay 호출 한도 초과 시 실제 버스·환승 경로 대신 내장 철도망을 사용합니다. 내장 경로는 운행시간·막차·실제 배차·급행·추가요금을 검증하지 않습니다. OSRM 자동차 소요시간과 택시 요금은 추정이며 실시간 교통을 반영하지 않습니다. 도로 조회 실패 시 직선거리 ×1.4와 평균 35km/h를 사용하며 실제 도로를 나타내지 않습니다. 최종 이동은 카카오맵/네이버지도에서 확인하세요.

Cloudflare Worker는 별도 서비스이며 이 저장소에는 서버 코드가 없습니다. 제공업체의 데이터 정확성·가용성·API 한도는 이 수정으로 보장되지 않습니다. 브라우저에서 사용하는 API 키는 화면을 가려도 소스/요청에서 열람할 수 있으므로 제공업체의 도메인·쿼터 제한이 필요합니다. 서버용 비밀 키는 Worker에 보관해야 합니다.
