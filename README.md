# 가는길 계산
대중교통·택시·자가용 시간과 비용 비교. GitHub Pages에서 index.html을 제공합니다.

## 검증 수정 (2026-10-01)
- 대안 경로 선택 시 상단 비교·탭·상세 시간과 요금이 함께 갱신됩니다.
- 성인 동행 1~4명의 대중교통 총액과 차량 1대 비용, 1인 비용을 비교합니다.
- 같은 표시시간의 택시와 자가용에 모두 ‘예상 최단’을 표시합니다.
- 한국시간으로 입력·요금 할증을 계산하고 자정 이후 도착에는 ‘다음날’을 표시합니다.
- 현재에서 15분 넘게 떨어진 출발에는 실시간 도착정보와 현재 고속도로 정체를 적용하지 않습니다. 미래 운행·막차를 예측하지 않습니다.
- 열차 수신시각이 5분 넘게 오래됐거나 시각이 불명확하면 안내를 중단합니다. 수신 후 지난 시간을 대기시간에서 차감합니다.
- 늦게 받은 도착 응답은 새 경로를 덮어쓰지 않고, 실패한 요청은 즉시 재시도할 수 있습니다.
- 선택한 장소의 좌표·주소·근사 위치 여부와 동행 인원을 검색 기록에 보존합니다. 기존 검색 기록도 읽을 수 있습니다.
- 조회 중 조건 변경을 막고 요청 당시 입력으로 계산·요약·검색 기록을 저장합니다.
- 대중교통 경로를 확인하지 못하면 가상 철도 시간·요금을 추천하지 않습니다.
- 버스 구간 보완 후 경로를 다시 정렬합니다.
- 화면 변경으로 중단되던 자동 테스트를 복구했습니다.

## 이전 검증 수정 (2026-09-30)
- 택시 총액과 요금 범위에 통행료를 정확히 합산합니다. 심야할증은 미터요금에 적용합니다.
- 연비·기본거리·요금 단위의 0, 음수, 잘못된 숫자를 검증합니다.
- 정수·소수 좌표를 지원하고 위도·경도 범위를 확인합니다.
- 입력 변경·장소 선택·출발지 교환 시 이전 자동완성 요청과 예약 작업을 무효화합니다.
- 중복 계산을 막고, 도로 조회 실패 시 경고와 점선으로 구분한 추정값을 제공합니다.
- 동일 ODsay 경로는 3분간 캐시하며 호출 한도 오류 후 5분간 재호출을 중단합니다.
- 이동 방향을 확인한 열차만 도착정보로 안내합니다.
- 손상된 검색 기록, 네트워크 실패, 오래된 역 도착 응답을 방어합니다.
- 설정 저장 시 경로를 다시 계산해 도보 속도와 주변 역 설정도 반영합니다.

## 검증
Node.js 18 이상에서 `node tests/regression.cjs` 실행. 계산·입력·캐시·장애 복구·선택 경로 동기화·한국시간·정보 신선도·검색 기록 40개 검증 그룹.

## 정확도와 운영 한계
공개 HTML에 포함돼 있던 기본 API 키를 제거했습니다. ODsay 실경로 조회는 사용자가 발급한 키를 설정에 입력해야 합니다. 키가 없거나 ODsay 호출 한도 초과 시 실제 버스·환승 경로 대신 내장 철도망을 사용합니다. 내장 경로는 운행시간·막차·실제 배차·급행·추가요금을 검증하지 않습니다. OSRM 자동차 소요시간과 택시 요금은 추정이며 실시간 교통을 반영하지 않습니다. 도로 조회 실패 시 직선거리 ×1.4와 평균 35km/h를 사용하며 실제 도로를 나타내지 않습니다. 최종 이동은 카카오맵/네이버지도에서 확인하세요.

Cloudflare Worker는 별도 서비스이며 이 저장소에는 서버 코드가 없습니다. 제공업체의 데이터 정확성·가용성·API 한도는 이 수정으로 보장되지 않습니다. 브라우저에서 사용하는 API 키는 화면을 가려도 소스/요청에서 열람할 수 있으므로 제공업체의 도메인·쿼터 제한이 필요합니다. 서버용 비밀 키는 Worker에 보관해야 합니다.

## 다음 개선 권고 (현재 구현에 포함하지 않음)
1. 별도 Worker에 대중교통 경로 조회를 추가해 이용자가 API 키를 직접 입력하지 않아도 정확한 버스·환승 경로를 사용할 수 있도록 합니다. 제공업체 약관·쿼터·허용 도메인을 확인하고 서버용 키를 Worker에 보관해야 합니다. 이 저장소에는 해당 Worker 원본과 운영 권한이 없습니다.
2. 실제 교통을 반영하는 자동차 경로와 통행료 제공 API로 OSRM/혼잡계수 추정을 보완합니다. 현재 OSRM 자동차 시간은 실시간 교통 예측이 아닙니다.
3. 노선·운행·배차를 지원하는 시간 의존 경로 제공 API를 확보한 뒤 예약 출발과 막차 확인을 확장합니다. 현재 ODsay 결과와 내장 노선망은 선택한 미래 출발시간의 운행을 검증하지 않습니다.
4. ‘도보 최소·환승 최소’ 선택은 실제 경로 후보의 총 도보 시간과 환승 횟수를 기준으로 추가하고, 엘리베이터·교통약자 정보는 공식 데이터가 확보된 구간에서만 제공합니다.

비용 비교는 성인 교통카드 요금과 차량 1대 기준입니다. 무료·경로·청소년 요금은 별도 적용하지 않습니다. 차량 유지비·승차 대기·주차 이동은 제외하며, 통행료·주차비는 입력한 금액만 합산합니다. 택시는 서울 중형택시 요율 가정이며 지역·시계외 할증 및 실제 저속운행 시간은 검증하지 않습니다.
